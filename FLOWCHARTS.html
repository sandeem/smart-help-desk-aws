🔵 Pipeline A — Ingestion (The Indexer)
You drop an FAQ file into S3. That event automatically triggers the ingest-fn Lambda (private subnets, ec2-sg) to read the file through the free S3 Gateway Endpoint, chunk the text, embed it with Bedrock via the Interface Endpoint, and store it in RDS pgvector.

🟢 Pipeline B — Query (EC2 + ALB Answer Engine)
A user's question comes in through the Internet Gateway to the Application Load Balancer (public subnets), which forwards it to the EC2 API server (private subnets). EC2 embeds the question via the Bedrock Interface Endpoint, searches pgvector, then asks Nova Micro for a cited answer.

🟡 Infrastructure View — Hybrid VPC (Lambda + EC2/ALB)
The full picture. Ingestion is serverless (S3 → Lambda). The query API is enterprise (Internet Gateway → ALB in public subnets → EC2 in private subnets). NO NAT Gateway: private compute reaches S3 over a free S3 Gateway Endpoint and reaches Bedrock over a Bedrock Interface Endpoint (PrivateLink). Three-tier security group chain: alb-sg (80 from the world) → ec2-sg (8000 from alb-sg) → rds-sg (5432 from ec2-sg). The Lambda reuses ec2-sg, so it inherits the same chain.
